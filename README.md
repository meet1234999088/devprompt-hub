# DevPrompt Hub

DevPrompt Hub is an open-source prompt library for developers.

It lets users:
- Browse reusable prompts
- Search prompts
- Organize prompts by category
- Create and save new prompts
- Open a prompt on its own page and copy it

## Why this project?

Developers repeatedly write similar instructions for coding, debugging,
documentation, testing, and research. DevPrompt Hub provides a simple
place to save and reuse those instructions.

## Local setup

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open http://127.0.0.1:5000
